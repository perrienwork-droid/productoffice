Container wrap, mono numbering, disc-color stripe

Reads well

  • Disciplines surface without adding chroma (just a 3px stripe + mono color)
  • Mono numbering ties the section to the rest of the library's reference rhythm
  • Container makes 8 floaters read as one "deck of prompts"
  • Hover lift borrows the topic-card behaviour from the rest of the home

Trade-offs

  • Container adds vertical weight, can feel boxy if the hero is busy
  • Stripe is subtle, may read as decoration rather than taxonomy on first scan
  • Mono numbering is invented (Q.UX.04), needs a rule we'd commit to
Variant B1, micro choice
Number as a top-right badge instead of inline top
Same combo, but the mono Q.UX.04 moves to the top-right corner as a quiet badge (mirrors the ★ Anchor tag in anchor-cards-variants.html). Question reads first, identifier second. Arrow is removed (the badge does enough).
